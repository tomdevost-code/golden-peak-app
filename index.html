Airtable connection

How to get your credentials

  1. Go to airtable.com/create/tokens while logged in
  2. Click Create token and name it Golden Peak App
  3. Add scopes: data.records:read and data.records:write
  4. Under Access select your Golden Peak Cannabis Inc. base
  5. Click Create token and paste it above
  6. For Base ID and Table IDs open your base in Airtable and copy the app and tbl values from the browser URL
